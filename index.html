🌍 Язык и встраивание

Переводит только служебные подписи игры (кнопки, подсказки, сообщения). Заголовок, вопросы и ответы остаются в том языке, на котором ты их написал(а).

⚡ Быстрый ввод вопросов списком

Три колонки, строки соответствуют друг другу по номеру: вопрос №1 слева — это ответы №1 в двух других колонках, и так далее. В каждой колонке с ответами можно указать несколько вариантов через |; регистр не важен. Если колонку «Неправильные» для строки не заполнять — получится вопрос «Вписать ответ» (текстовое поле). Если заполнить и указать один правильный вариант — получится «Один вариант ответа» (кнопки), если несколько правильных — «Несколько вариантов ответа» (галочки). Для типов «Расставить по порядку» и «Без ответа» — используй импорт из CSV ниже или карточки в банке вопросов.

📊 Импорт из CSV / Google Таблицы

Работает со всеми 5 типами вопросов сразу. Колонки: Тип, Вопрос, затем сколько угодно колонок с ответами. Для «Один вариант ответа» первый ответ — правильный. Для «Несколько вариантов ответа» отметь правильные звёздочкой * перед текстом. Для «Вписать ответ» перечисли все принимаемые варианты. Для «Расставить по порядку» впиши элементы в правильном порядке слева направо. Для «Без ответа» колонки с ответами не нужны. Скачай шаблон, чтобы увидеть пример — его удобно открыть и заполнить в Google Таблицах или Excel.

🏷️ Тексты игры

🚪 Титульный экран

Экран приветствия перед началом игры — показывает название и подзаголовок (цель игры) до того, как откроется поле. Использует те же «Заголовок игры» и «Подзаголовок» из панели выше.

🏆 Экран победы — тексты

Оставь поле пустым, чтобы использовать перевод по умолчанию (зависит от языка). Впиши свой текст — он полностью заменит стандартный.

❓ Окно вопроса — тексты

Тоже переведены по умолчанию — оставь пустым или впиши свой вариант.

👁️ Предпросмотр

ℹ️ Как пользоваться предпросмотром
Предпросмотр обновляется автоматически при изменении полей. Переключи на «Титульный экран» или «Окно победы», чтобы сразу видеть правки текста/цвета/шрифта — без прохождения игры (титульный экран показывается тут независимо от галочки «Показывать титульный экран», чтобы его было удобно проверить). Когда всё готово — нажми «Скачать готовую игру .html» в шапке: получится отдельный файл, который можно открыть в браузере или отправить кому угодно.

💡 Формулы: оберни LaTeX-код знаками доллара, например $x^2+1$ или $\frac{a}{b}$ — редактор покажет их как настоящие формулы. Обычный текст с любыми символами (тире, кавычки, двоеточия) отображается как есть и не ломается.
